# ‘농업기술명인’, 유기적 협력 체계 구축으로 지역 농업 발전 견인

농촌진흥청(청장 이승돈)은 11월 24일 전남광주통합특별시 여수시에서 ‘대한민국 최고농업기술명인회(이하 명인회)’ 주관으로 2026년 최고농업기술명인 공동 연수회(워크숍)가 열렸다고 밝혔다. 이번 연수회는 최신 농업기술 동향을 공유하고, 명인 간 유대감을 강화함으로써 명인회 역할을 확대하고 지속 가능한 발전 방안을 찾기 위해 마련됐다. 이날 농업기술명인들은 지역 농업의 미래를 이끌어갈 차세대 농업 인재에게 장학금을 수여했다. 또한, 직접 생산한 농산물을 전남 지역 사회복지시설에
