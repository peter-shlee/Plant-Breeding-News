# 농촌진흥청, 여과 액비로 경축 순환 농업 확산 방안 찾아

농촌진흥청 김상경 차장은 11월 23일 충남 공주시 우성면에 있는 ‘여과 액비 활용 경축순환농업 시범사업장’을 방문해 사업 추진 현황을 살펴보고, 시범 사업 참여 농가 의견을 청취했다. 이번 방문은 시설 채소 관수(물·양분 공급) 시스템에 여과 액비를 적용했을 때 생산성 향상 효과를 확인하고, 농가 의견을 반영해 기술 확산 방안을 찾기 위해 마련됐다. ‘여과액비’는 가축분뇨나 유기물을 발효시켜 만든 액체 상태 비료에서 완전히 분해되지 않은 유기물
