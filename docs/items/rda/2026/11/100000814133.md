# “베트남 딸기 수출길 더 넓어진다” 농약 안전사용지침 개발

농촌진흥청(청장 이승돈)은 딸기 수출 농가가 베트남 농약 안전사용기준에 맞춰 농약을 선택하고 사용할 수 있도록 농약 안전사용지침을 개발해 보급했다. 우리나라 딸기 수출은 지난해 4,864톤, 7,040만 달러(한화 약 1,003억 원)를 기록해 신선 농산물 중 1위를 차지하고 있다. 베트남은 지난해 금액 기준 태국(27.4%), 싱가포르(27.1%), 홍콩(13.9%)에 이은 딸기 수출 4위(10.4%) 국가다. 그동안은 베트남 전용 농약 안전사용지침이 없었기 때문에 수출 농가와 수출업체에서는 사용
