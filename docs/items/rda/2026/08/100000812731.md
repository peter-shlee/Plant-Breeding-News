# “방제기가 과수원 정보 기억” 작업자 없이 농약 살포한다

농촌진흥청(청장 이승돈)은 8월 28일 전북특별자치도 장수군농업기술센터 사과 시험 재배지에서 ‘경로 학습 기반 무인 고성능 방제기(스피드 스프레이어*)’ 현장 연시회를 연다. * 스피드 스프레이어(SS기): 농약을 송풍 공기로 안개처럼 만들어 살포하는 주행식 동력분무기 농촌진흥청 국립농업과학원, 장수군농업기술센터가 함께 주관하는 이번 행사에는 공동연구기관인 ㈜아세아텍과 한국농수산대학교, 전북특별자치도농업기술원, 지역 농업인 등 30여 명이 참석한다. 이날 참석자들은 방제기 시연
