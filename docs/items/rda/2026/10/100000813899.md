# 팽이버섯 고깔 세척‧건조 기계화로 ‘위생 관리’ 효율 높인다

농촌진흥청(청장 이승돈)은 10월 29일 충청북도 음성군 팽이버섯 현장 실증 농가에서 ‘팽이버섯 고깔(권지)* 세척‧건조 장치 현장 평가회’를 연다. * 팽이버섯 고깔(권지): 팽이버섯의 벌어짐을 방지하는 필름 형태의 농자재 팽이버섯 고깔은 재배 과정에서 팽이버섯의 벌어짐을 방지하기 위해 사용하는 농자재이다. 팽이버섯 재배 농가에서는 고깔을 세척해 여러 번 사용하기 때문에 안전한 품질의 팽이버섯을 생산하려면, 고깔 위생에 신경 써야 한다. 하지만 하루 평균 사용 고깔만 약 2만
