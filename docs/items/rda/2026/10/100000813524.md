# 농촌진흥청, ‘농생명 분야 전문가 인공지능’ 개발

농촌진흥청(청장 이승돈)은 농생명 분야 논문과 국가 연구 데이터로 인공지능 모형(모델)을 학습시켜 ‘농생명 특화 거대언어모델(LLM*)’을 개발하고 10월부터 활용한다. * 거대언어모델(LLM): 대용량 인간 언어를 이해하고 생성할 수 있도록 훈련된 인공지능 모형 현재 일반적으로 사용되는 범용 거대언어모델은 우리나라 농업 관련 정보와 이해도가 부족해 원하는 자료를 찾기 어렵다는 한계가 있다. 또한, 외부 서비스로 보안 관련 문제가 발생할 우려도 있어 그동안 사용하기 어려웠다. 연구진은 원예‧
