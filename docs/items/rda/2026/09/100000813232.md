# 농촌진흥청, 코피아센터 파견 연구원 17명 공개 채용 - 일반·통역연구원 아시아 대륙 7명, 아프리카 8명, 중남미 2명 모집 - 9월 28일∼10월 8일까지 응시 원서 온라인 접수
