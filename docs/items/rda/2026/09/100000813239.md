# “딸기 중소형 스마트팜 생산성 향상 기술” 현장 적용성 살핀다

농촌진흥청(청장 이승돈) 국립농업과학원은 ‘딸기 단동형 스마트팜 생산성 향상 융합 모형’을 개발해 현장 실증 연구를 추진 중이다. 이는 스마트팜 구축 비용 증가와 농가 간 생산성 차이 등에 대응해 기존 시설을 최대한 활용하면서 농업인이 필요한 기술을 선택해 적용하는 기술이다. 이와 관련해 성제훈 국립농업과학원장은 9월 28일 전남광주통합특별시 담양군 월산면에 있는 딸기 중소형 스마트팜 현장 실증 농가를 방문해 연구과제 추진 상황을 둘러보고 농가 의견을 청취했다.
