# ‘2026년 전국 청년농업인 교류 행사’ 개최

농촌진흥청(청장 이승돈)은 9월 3일부터 5일까지 전남광주통합특별시 고흥군 고흥만 수변노을공원 일원에서 한국4-에이치(H)중앙연합회 주관으로 ‘2026년 전국 청년농업인 교류 행사(이하 청년농업인 교류 행사)’*가 열린다고 밝혔다. *주최: 농촌진흥청, 전남광주통합특별시, 고흥군 주관/후원: 한국4-H중앙연합회 / 한국4-H중앙본부, 농협중앙회 등 한국4-에이치(H)중앙연합회는 농촌진흥청이 육성하는 농업인 학습단체로, 청년농업인과 예비 청년농업인이 회원으로 가입해 활동 중이다.
